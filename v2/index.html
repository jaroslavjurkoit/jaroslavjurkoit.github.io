REQ-14

Partial goods receipt

As a buyer, I want to record deliveries line by line, so that partly delivered orders don't block invoicing.

Acceptance criteria

  1. 1The buyer enters a received quantity for each order line.
  2. 2A quantity above the open quantity is rejected with a clear message.
  3. 3Saving creates a goods receipt with date, user and lines.
  4. 4When every line is fully received, the order becomes "Received".
  5. 5Every receipt appears in the order's history.

Hover or tap a criterion to see where it lands.

    This screen works: fix the quantity and save the receipt.

    API contract

    POST/purchase-orders/{id}/receipts 201 Created
    body { "lines": [ { "lineId": "L-2", "quantity": 6 } ] }
    422 QUANTITY_EXCEEDS_OPEN { lineId, open }
    event PurchaseOrderFullyReceived status = RECEIVED
    GET/purchase-orders/{id}/receipts

    Data model

    1. UI

      Buyer types 6 into "Receive now" for line L-2

      The form only offers lines with an open quantity

    2. API

      POST /purchase-orders/1042/receipts

      One call per receipt, lines in the body

    3. Rule

      quantity ≤ open, else 422 QUANTITY_EXCEEDS_OPEN

      The UI shows the same message the API returns

    4. DB

      goods_receipt + receipt_line rows, received_qty updated

      Date and user stored with the receipt

    5. Domain

      All lines received → status = RECEIVED

      Event lets invoicing start matching

    6. UI

      History shows the new receipt, badge updates

      Read from GET …/receipts
